EDITING A CARD
Open the file named:

card-data.js

Each card looks like this:

{
  "number": 2,
  "unlocked": false,
  "title": "Card 2",
  "heading": "Your heading",
  "message": "The message or clue underneath the scratch layer.",
  "closing": "A final short line."
}

To unlock Card 2, change:

"unlocked": false

to:

"unlocked": true

Then add its heading, message and closing text.

IMPORTANT: CURRENT STATIC VERSION
This file-based version is useful for designing and testing the site.

If you host this folder online, you can update card-data.js and upload the changed
file to the same hosting project. The public link can stay the same after the site
is redeployed.

However, this is not yet a live admin system. You cannot currently press an unlock
button on your phone and have her page update instantly.
